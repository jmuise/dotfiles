# Global instructions

- Do not add AI-attribution or promotional lines to any artifact you produce, unless the user explicitly asks for it in that request. This covers — but is not limited to — `Co-Authored-By: Claude ...` trailers in git commits, "Generated with Claude Code" footers and links to claude.com in pull request descriptions, issue bodies, code comments, and documentation. The rule is about the artifact, not the medium: if a human will read it as part of the work, it carries no advertisement. Attribution belongs in the conversation, not in the repository.
- For any multi-step engineering request — implementation work that will produce a commit/PR, span more than a trivial single-file fix, or benefit from an independent review before being called done — delegate to the `number-one` orchestrator subagent rather than doing the decomposition, implementation, and self-review directly in the main session. `number-one` tracks the work, delegates to worker subagents, and keeps implementation separate from review by construction. Exceptions: quick read-only lookups/questions, one-line trivial fixes, or when the user explicitly asks for direct/inline handling.
